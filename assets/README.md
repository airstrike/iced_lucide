# Bundled Lucide font

The default icon font and its matching HTML name index come from the official [`lucide-static` 1.72.0 release](https://www.npmjs.com/package/lucide-static/v/1.72.0). `lucide.ttf` and `unicode.html` are unmodified copies of `font/lucide.ttf` and `font/unicode.html` in that release. The [license](LICENSE) covers both files.

For an update, fetch the [official package tarball](https://registry.npmjs.org/lucide-static/-/lucide-static-1.72.0.tgz) for the chosen version and verify its SHA-512 integrity against the npm registry metadata. Copy the two font files and the package license together. The HTML index lists the drawable font glyphs. The package's JSON index also contains historical names for removed glyphs.
